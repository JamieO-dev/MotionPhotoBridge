## Add the page to your repository

1. Put this package’s `README.md` at the root of your MotionPhotoBridge source repository, alongside `Package.swift` and `Build MotionPhotoBridge.command`.
2. Put the `assets` folder at the same level. Keep the three PNG filenames unchanged so the README image links work.
3. Include the package’s `docs` folder. It retains the validation and Mac verification guides, preserves the longer technical guide, and adds a native screenshot capture guide.
4. Add the About description and whichever topics fit your repository.
5. Preview the README on GitHub before publishing the changes.

The README is the repository’s front page. No GitHub Pages hosting or deployment is required to display it.
